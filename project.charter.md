# Project Charter: AI-Driven Ticket Routing System

## 1. Business Problem
Current manual ticket routing is inefficient, leading to high resolution times and human errors in department assignment.

## 2. Stakeholders
- Support Agents: Reduce manual triage time.
- Customer Success Leads: Improve CSAT scores.
- Management: Optimize operational costs.

## 3. AS-IS Process
- Manual reading -> Manual categorization -> Manual routing -> High latency.

## 4. TO-BE Process (The AI Solution)
- Automated NLP classification -> Rule-based routing -> Human-in-the-loop validation -> Reduced latency.
